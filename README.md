The Student Result Analyzer is a simple web application developed using Python and the Streamlit framework. The main purpose of this application
is to analyze a student's academic performance based on the marks entered for different subjects.
The application allows the user to enter the student's name and marks for subjects such as Math, Science, English, and Python. 
Once the user clicks the Analyze Result button, the system automatically calculates the total marks and average marks. Based on the 
average score, the application determines whether the student has passed or failed.

The application also displays the results in a clear and interactive format. It shows the student details, calculated results,
and a subject-wise bar chart that visually represents the marks. The chart is generated using the Python visualization library matplotlib.

This application demonstrates how Python can be used to build interactive web applications for data analysis and visualization. 
It provides a user-friendly interface and helps users easily understand student performance through graphical representation.
